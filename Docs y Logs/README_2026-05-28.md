### obra.py
- `MASTER_DB` apunta a `Master_Obras.db`
- Clase `Obra` suma campos `id_comitente`, `estado` y `subrubro`
- **`_build_id_rs_lookup()`** — nueva función que construye el mapeo `id_rs → rubro padre`
  y `id_rs → subrubro`, usando los rangos de la tabla `rubros`
- **`cargar_maestro_desde_db()`** — reescrita para el nuevo esquema:
  - Agrupa tareas por **rubro padre** (no subrubro)
  - Cada tarea incluye campo `subrubro` para uso futuro
  - Si `id_rs` no cae en un subrubro hijo, cae al rubro padre (cubre Marmolería, Conductos, Vidrios, etc.)
- **`crear_base_particular()`** — valida el esquema de `BaseParticular.db` al abrir cada obra;
  si está desactualizado lo recrea automáticamente desde `Master_Obras.db`
- **`conectar_base_particular()`** — siempre pasa por la validación de esquema antes de conectar
- **`_actualizar_db()`** — guarda `comitente_texto` en la tabla `obras`
- **`listar_obras()`** — `COALESCE(c.nombre, o.comitente_texto)` para mostrar comitente
- **`_completar_desde_db()`** — mismo criterio al cargar una obra
- Nuevas funciones públicas: `listar_comitentes()`, `crear_comitente()`
